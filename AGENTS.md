# KnightForge project rules

- Read existing files before making changes.
- Never rebuild working features unnecessarily.
- Every feature must use real data or clearly labeled demo data.
- Never fabricate chess moves, evaluations, or statistics.
- Prefer free and local functionality.
- Keep API keys secure.
- Work only on the feature requested in each prompt.
- Avoid unnecessary dependencies and large refactors.
- Run relevant checks after implementation.
- Record progress and next steps in `docs/HANDOFF.md`.
- Stop when the requested phase is complete.
